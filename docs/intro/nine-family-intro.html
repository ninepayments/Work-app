로그인 · 설치 · 업데이트

시작하기

로그인

📍 첫 화면👤 등록된 직원
  • 관리자가 등록한 내 휴대폰 번호를 넣고 ‘인증번호 받기’ → 문자로 온 6자리를 넣으면 로그인돼요. 6자리를 다 치면 저절로 확인해요.
  • 한 번 로그인하면 계속 유지돼요. 기기를 바꿔도 같은 번호로 로그인하면 모든 자료가 그대로예요(자료는 서버에 있어요).
  • ‘등록되지 않은 번호입니다’ → 관리자에게 번호 등록 요청. 짧은 시간에 여러 번 요청하면 30분쯤 막힐 수 있어요.
  • 사람 확인(로봇 확인)은 로그인 화면이 열릴 때 미리 준비해서 인증번호 받기를 기다리는 시간을 줄였어요.

기기별 설치

📍 -👤 모든 직원
  • 안드로이드 앱: APK 파일을 받아 설치(처음 한 번 ‘이 출처 허용’).
  • 아이폰: 사파리로 웹앱 주소를 열고 공유 → ‘홈 화면에 추가’ 하면 앱처럼 써요.
  • 윈도우 PC: 설치 파일(NineFamily-Setup.exe)을 실행하면 바탕화면·시작 메뉴에 나인패밀리가 생겨요. 처음 ‘Windows의 PC 보호’ 창이 뜨면 ‘추가 정보’ → ‘실행’.
  • 세 기기가 같은 서버를 써서 어디서 고쳐도 다른 기기에 바로 보여요.

업데이트

📍 ☰ → 내 계정·설정 → 업데이트 확인👤 모든 직원
  • 안드로이드 앱: 앱을 열면 새 버전을 찾아 ‘업데이트’ → ‘설치’ 안내가 떠요. 앱 안에서 내려받아 바로 설치해요.
  • 웹앱·PC: 화면 위에 ‘지금 업데이트’ 띠가 뜨면 누르기, 또는 새로고침(F5)·프로그램을 껐다 켜면 최신이에요(10분마다 확인).
  • 버전은 ☰ → 내 계정·설정 → 버전·업데이트 내역에서 바뀐 내용과 함께 봐요.

화면 구성과 공통 기능

휴대폰 화면

📍 안드로이드 앱 · 아이폰 웹앱👤 모든 직원
  • 아래 탭: 업무 · 프로젝트 · 채팅 · 일정 · ☰(전체). 나머지 기능은 ☰ 안에 있어요.
  • 안 본 개수는 탭 오른쪽 위 빨간 동그라미 숫자로 보여요(업무 미확인, 안 읽은 채팅, 새 공지·입고 확인).

PC 화면

📍 윈도우 PC · 넓은 화면 브라우저👤 모든 직원
  • 위쪽 주 메뉴: 업무 · 프로젝트 · 채팅 · 일정 · 가맹점 · 응대 기록 · 메모. 로고를 누르면 홈(오늘 현황).
  • 홈 ‘오늘 현황’: 새 업무·진행 중·오늘 일정·안 읽은 채팅·이번 주 응대 기록 수, 내 업무, 오늘 일정, 공지.
  • 왼쪽 칸: 화면마다 바로가기 목록(기한 지난 업무·내 업무, 진행 중인 가맹점 업무, 최근 연 가맹점, 이번 주 일정, 같은 묶음 메뉴).
  • 왼쪽 위 ☰ 를 누르면 전체 메뉴가 화면 전체에 펼쳐져요.

☰ 전체 메뉴와 기능 검색

📍 ☰👤 모든 직원(권한별로 보이는 메뉴가 달라요)
  • 9개 묶음: 내 계정·설정 · 업무 · 가맹점 · 계약 · 재고 · 실적 · 보고 · 회사 · 관리자.
  • 맨 위 기능 검색에 단어나 초성(예: ㅈㄱ → 재고)을 치면 기능을 바로 찾아요.
  • 권한이 없는 메뉴는 아예 보이지 않아요.

한글 검색

📍 모든 검색칸👤 모든 직원
  • 초성(ㅅㅇㅍㄷ), 치는 중인 글자(‘삼영ㅍ’), 사업자번호·전화번호(- 없이도)로 찾아요. 한글을 치는 동안에도 바로 걸러져요.

저장 상태 · 인터넷 끊김

📍 화면 위 띠👤 모든 직원
  • 저장하면 ‘저장 중’이 잠깐 보여요. 인터넷이 끊기면 ‘저장 대기’로 바뀌고, 연결되면 저절로 서버에 올라가요(웹).
  • 받아 둔 자료로 인터넷이 없어도 보기·입력이 돼요.

뒤로가기

📍 폰 뒤로가기 · 브라우저 뒤로👤 모든 직원
  • 팝업 → 대화방 → 메뉴 → 하위 화면 → 첫 화면 순서로 한 단계씩 닫혀요. 첫 화면에서 한 번 더 누르면 나가요.
요청 · 처리 · 응대 기록 연결

업무

업무 목록

📍 아래 탭 업무 · PC 업무👤 모든 직원
  • 위쪽 금색 카드에 남은 업무 수(미확인·진행·보류, 오늘 완료).
  • ‘상태별로 보기’: 미완료 · 미확인 · 진행중 · 보류 · 완료.
  • ‘전체 업무 보기’ 권한이 있으면 내 업무 / 전체 업무를 바꿔 봐요.
  • 계약 만료가 3개월 안으로 남은 계약이 있으면 위에 빨간 알림 카드가 떠요.

업무 요청하기

📍 업무 화면 + · ☰ → 업무 → 업무 요청하기👤 업무 만들기 권한(다른 사람에게는 배정 권한)
  • 제목 · 종류(신규 설치·AS·서류 접수·카드사 서류·기타 등) · 거래처 · 전화 · 주소 · 기한(날짜·시간) · 메모 · 담당 직원.
  • 가맹점 조회로 고르면 거래처·전화·주소가 자동으로 채워져요. 못 찾으면 그 자리에서 새 가맹점 등록 후 자동 연결(가맹점 권한·암호 필요).
  • 가맹점 요청사항: 빠른 선택 버튼(예: ＋ 용지신청)과 직접 입력. 버튼은 관리자가 추가·편집해요.
  • 기한을 넣으면 일정 달력에도 표시돼요. 서류 업무는 ‘서류접수’ 채팅방에 자동으로 알림이 올라가요.
  • 담당자 폰에 ‘띵동’ + “업무가 배정되었습니다” 음성 알림.

업무 처리

📍 업무를 눌러서👤 담당자 · 최고관리자
  • 진행 시작 → 보류·연기(다시 할 날짜) → 완료(처리결과). 상태는 담당자 본인과 최고관리자만 바꿔요.
  • 완료 때 적은 처리결과는 가맹점 요청사항과 함께 그 가맹점 응대 기록에 자동으로 남아요(📋 업무에서 표시).
  • 담당자가 처음 열어 본 시각, 일정 변경, 상태 변경이 모두 처리 이력에 남아요.
  • 삭제는 업무를 만든 사람과 최고관리자만.

지난 업무 기록

📍 ☰ → 업무 → 지난 업무 기록👤 모든 직원(전체 이력 권한이 없으면 내 것만)
  • 완료된 업무를 제목·거래처·담당자·완료 메시지로 찾아요.
체크리스트와 진행률

프로젝트

프로젝트

📍 아래 탭 프로젝트 · PC 프로젝트👤 모든 직원
  • + 로 이름·마감일·메모·체크리스트(한 줄에 하나)·담당자를 넣어 만들어요.
  • 항목을 체크하면 진행률이 자동으로 올라가고 ‘항목 추가’로 늘려요. 100%면 완료, ‘완료 되돌리기’도 돼요.
  • 전체·진행중·완료로 걸러 봐요. (앱: 항목 삭제·진행 기록도)
사내 메신저

채팅 (나인톡)

대화방

📍 아래 탭 채팅 · PC 채팅👤 모든 직원
  • ‘+ 새 채팅’ → 그룹 채팅방 또는 1:1 대화. 직원은 이름·초성·번호로 찾고, 많으면 ‹ › 로 넘겨요.
  • 1:1 대화는 두 사람만 볼 수 있어요(서버에서도 막혀 있어요).
  • 사진·파일(3MB까지), 이모지, 나인이 프렌즈 스티커 80종, 글 속 웹 주소는 눌러서 열려요. 사진은 크게 보고 저장.
  • 말풍선을 누르면 반응(👍 ❤️ 😂 …)·답장·복사·삭제(내 것), 두 번 빠르게 누르면 ❤️.
  • 말풍선 옆 노란 숫자 = 아직 안 읽은 사람 수. 읽음은 계정 단위라 PC에서 읽으면 폰에서도 읽음이 돼요.

채팅 알림

📍 -👤 모든 직원
  • 새 메시지가 오면 카톡처럼 짧고 밝게 “나인톡!”.
  • 채팅방마다 소리 끄기: 웹은 방 위 🔔/🔕, 앱은 대화방 메뉴 → 음소거.
  • (앱) 대화방 메뉴: 대화 검색, 참여자·방 정보, 이름 변경, 배경화면 변경, 대화 내용 비우기, 대화방 삭제.
공휴일 · 업무 기한

일정 (달력)

달력

📍 아래 탭 일정 · PC 일정👤 모든 직원(일정 추가·삭제는 최고관리자)
  • 일요일·공휴일 빨간색(공휴일 이름, 2026~2028년), 토요일 파란색. ‹ › 로 달 이동, ‘오늘’로 돌아와요.
  • 날짜를 누르면 그날 일정과 기한이 있는 업무, 아래에 ‘다가오는 일정’이 날짜순으로 나와요.
  • 가맹점이 연결된 일정은 ‘가맹점 정보 보기’로 바로 가요. 일정 추가 때 가맹점을 고르면 장소에 주소가 들어가요.
  • 일반 직원은 업무에 기한을 넣으면 달력에 표시돼요.

내 프로필

알림 및 소리 설정

📍 ☰ → 내 계정·설정 → 알림 및 소리 설정👤 모든 직원(기기마다)
  • 업무 알림 소리: ‘띵동’ + “업무가 배정되었습니다”(물품요청 “물품요청이 들어왔습니다”, 발송 “물품이 발송되었습니다”, 공지 “새 공지가 있습니다”). 켜기·끄기·▶ 들어 보기.
  • 채팅 알림 소리: “나인톡!”. 켜기·끄기·▶ 들어 보기.
  • (앱) 화면 꺼져도 알림 받기: 화면이 꺼져 있거나 앱을 닫아도 알림이 오고 화면이 켜져요. 처음 한 번 ‘배터리 절약에서 빼기’를 허용하면 돼요. 폰을 다시 켜도 저절로 다시 시작.
  • (웹·PC) 화면 알림(이 기기): 허용하면 다른 창을 보고 있어도 알림이 떠요. 탭 제목에 안 본 개수.

  • 계약 만료 예정 필터: 1·2·3개월 이내·만료됨 → 종료일 빠른 순, D-day 표시. PC는 표로 보여요.
  • 가맹점 화면에 전화 걸기, 진행 중인 업무, 응대 기록이 함께 보여요.
  • 같은 사업자번호가 이미 있으면 등록할 때 알려 줘요. 수정 창을 연 사이 다른 직원이 고치면 바뀐 항목을 보여 주고 다시 물어요(웹).

☰ 재고

재고

📍 ☰ → 재고 → 재고👤 모든 직원(단가는 실적 권한)
  • 보관지: 본사 · 광주지사. 보관지별로 나눠 보고, 장비의 보관지를 바꾸면 ‘이동’으로 이력에 남아요.
  • 입고: 상품(상품코드·이름) · 시리얼(한 줄에 하나, 스캐너로 계속 찍으면 여러 대) · 시리얼 없는 물품 수량 · 보관지 · 입고처 메모 · 안전재고 · 입고 단가.
  • 출고(계약 없이): 반품 · 불량·폐기 · A/S 교체(가맹점 연결) · 분실 · 기타.
  • 수량 정정(재고 조사): 실제 수량을 적고 없는 시리얼은 체크를 끄면 차이만큼 바로잡고 이력에 남아요.
  • 상품별 재고·출고중 수, 안전재고보다 적으면 빨간색. 실적 권한자는 입고·출고 단가와 보유 재고 자산.
  • 바코드: PC는 USB·블루투스 스캐너, 폰은 📷 카메라. 검색칸에 시리얼을 찍으면 그 장비가 바로 열려요. (앱) 시리얼 사진 인식도.
  • 흐름: 재고 → (계약에서 고르면) 출고중 → (설치 완료) 재고에서 빠짐.

  • 처음 재고를 옮길 때. 업로드 양식: 상품코드 · 상품명 · 시리얼 · 수량 · 현재위치 · 사업자번호 · 설치일 · 메모.
  • 현재위치가 본사·광주지사 → 우리 재고로 입고. 가맹점 상호 → 이미 설치된 장비로 기록만(재고 수·수익 제외). 가맹점을 먼저 올려 두세요.
  • 미리보기에서 입고 개수, 설치 장비 수, 새로 만들 상품코드, 못 올리는 줄과 이유를 보여 줘요.

물품요청 (본사 ← 지사)

📍 ☰ → 업무 또는 재고 → 물품요청 · 재고 화면 아래👤 모든 직원(처리는 본사 담당)
  • 받을 곳 · 품목과 수량(줄 추가) · 본사 담당자 · 희망 도착일 · 메모.
  • 품목은 재고 품목(상품코드·보관지별 재고 수)에서 고르거나, 없는 물품은 이름만 적어 ‘새 물품’으로 요청해요.
  • 본사 담당: “물품요청이 들어왔습니다” 알림 → 주문함 → 발송(송장 메모) 또는 반려(사유). 이때 새 물품은 상품 목록에 올라가고 코드가 붙어요.
  • 요청한 사람: “물품이 발송되었습니다” 알림 → 입고 확인(받은 수량·시리얼)하면 받은 곳 재고에 바로 들어가요.
  • 단계: 요청 › 주문함 › 발송함 › 입고완료(또는 반려). 모든 단계가 처리 이력에 남아요.

변경 기록

업무·가맹점·재고 같은 주요 자료는 저장할 때마다 누가 언제 무엇을 바꿨는지 기록됩니다(채팅·프로필 제외). 가맹점은 예전 내용으로 되돌립니다.

백업

관리자 기기에 하루 한 번 14일치 자동 보관, 백업 파일 내려받기. 서버 전체 암호화 백업은 백업 비밀값을 등록하면 매일 돕니다.
